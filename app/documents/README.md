# Editing the Documents

The HTML files in this repository are not particularly human-readable because the original documents were written in `.docx` format and later exported to HTML.

If you need to make changes, it is much easier to edit the source documents in Notion or Microsoft Word and then export them to HTML again.

## Converting Privacy Policy and Terms & Conditions to HTML

1. Create a new page in Notion.
2. Use **Import** to upload the `.docx` file containing the document.
3. Make any required edits.
4. Export the page as **HTML**.
