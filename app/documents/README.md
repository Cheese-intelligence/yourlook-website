# How did I convert privacy policy and T&C in html

1. Open a new page in notion
2. Paste /import and import the docx with the content you want
3. Export the imported file in html

After that we should just keep those documents in notion and edit them there as well to avoid extra work. Simply replace the `.html` files in this folder with your newly exported versions.
