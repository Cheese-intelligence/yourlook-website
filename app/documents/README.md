# How did I convert privacy policy and T&C in html

1. Open a new page in notion
2. Paste /import and import the docx with the content you want
3. Export the imported file in html

The notion page was created on `info.general1810@gmail.com` without password (sign in with google option). So, T&C [documents](https://app.notion.com/p/T-C-397cd18fd92e80049c4fe73be26fe832) and [privacy policy](https://app.notion.com/p/PrivacyNotice-397cd18fd92e8047b63fc2a9b6a80c54) are accessible in notion.
